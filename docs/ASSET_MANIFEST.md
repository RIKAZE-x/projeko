# VEILBOUND 2D Asset Manifest

The game uses a logical asset-ID layer so visual files can be replaced without changing gameplay data.

## Approved foundation sources

- Kenney RPG Base — 230+ 2D assets, CC0.
- Kenney Roguelike/RPG Pack — 1700+ 16x16 2D assets, CC0.
- Kenney Roguelike Caves & Dungeons — 520+ 2D assets, CC0.
- Kenney RPG Urban Pack — 480+ 16x16 2D assets, CC0.
- Kenney UI Pack (RPG Expansion) — 85 UI assets, CC0.
- Kenney Pixel UI Pack — 750+ 2D UI assets, CC0.

## Production rule

Do not scrape random images or use copyrighted game sprites. Each imported asset must have a recorded source and license. CC0 sources are preferred because they permit commercial use without attribution requirements. Custom VEILBOUND art should be added for signature characters, bosses, unique races, legendary equipment, Eclipse, and Void content.
